# Sources

Every figure in `experiments/table_recovery/inputs.json` was transcribed from the
full text of the article named here, not from an abstract or a review. The articles
are not redistributed. Each is identified by the sha256 of the text extraction the
figures were read from, so a reader who obtains the same article can confirm they
are reading what was read here.

The artifact filename is the name the file carries in the shared citations library
and does not always match the citation key: `heianza2012.txt` holds Inoue et al.,
and the key was corrected without renaming the pinned file.
